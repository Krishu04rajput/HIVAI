# HiVAI v1.1 — Core State Engine

v1.1 turns the futuristic HUD into an interactive state machine.

States:
- IDLE
- LISTENING
- THINKING
- SPEAKING

The UI includes a local console, browser speech recognition, animated core state indicators, activity logging and a module-status panel.

The actual AI model/backend is intentionally not hard-coded into the frontend. The next milestone is the secure backend gateway and AI adapter.
