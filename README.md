# HiVAI — Hive Intelligence Virtual AI System

HiVAI v1 is the web foundation of a personal, voice-first AI system.

## Current v1 UI
- Futuristic cyan/black command HUD
- Revolving central AI Core
- Animated orbital rings
- Voice-input interface
- System/resource panels
- Activity log
- Responsive mobile layout

The AI brain, secure backend, persistent memory, web research and tool system will be connected in later v1 milestones.

## Run
Open `index.html` in a modern browser, or deploy the repository with GitHub Pages.
